# Sécurité

Pour signaler une faille de sécurité dans l'app Crédit Immo ou dans ce site, utilisez
**[Report a vulnerability](https://github.com/francoisgn/ios-app_credit-immo-pub/security/advisories/new)**
(signalement privé GitHub). N'ouvrez pas d'issue publique.

Vous recevrez une réponse dès que possible.
